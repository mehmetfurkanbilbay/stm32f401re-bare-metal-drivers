# STM32F401RE Bare-Metal Drivers

This repository documents my journey of learning bare-metal programming on the STM32F401RE microcontroller.

The project is built from scratch without using the STM32 HAL library. Instead, every peripheral definition and driver is implemented by studying the official Reference Manual and Datasheet.

## Goals

- Learn the STM32F401RE architecture
- Understand the ARM Cortex-M4 memory map
- Implement peripheral drivers from scratch
- Build a reusable bare-metal driver library

